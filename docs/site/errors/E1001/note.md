E1001 is the parser's general syntax error: at some point it needed one specific token and found another, and the message names both (here `expected ')', found 'return'`). The position it points at is where the parser noticed the problem, which is often the line after the real mistake, so look just before it. Fix it by adding or correcting the token the message names, here the closing parenthesis of `balances.set(...)`.
