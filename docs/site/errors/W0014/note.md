W0014 flags an idiom that is valid Soma but probably does not mean what it would mean elsewhere. Here `??` binds looser than arithmetic, so `balances.get(owner) ?? 0 + amount` reads as `balances.get(owner) ?? (0 + amount)`: the first deposit stores `amount`, and every later deposit leaves the balance unchanged (a deposit of 100 then 50 gives 100, not 150). Parenthesize the default: `(balances.get(owner) ?? 0) + amount`.
