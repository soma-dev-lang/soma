`soma check` reads a program as UTF-8 text; when the file cannot be read (a missing path, or here a file saved in Latin-1, whose `é` is not valid UTF-8), it stops with "cannot read" and the JSON report (`soma check --json`) gives the code E0115. The plain-text output shows the message without the code, and the JSON `fix` field says "check the path" even when the path is right and the encoding is the problem. Save the file as UTF-8 (`iconv -f ISO-8859-1 -t UTF-8`); a UTF-8 byte-order mark at the start is accepted.
