An `ensure` runs where it stands, so when a handler can `return` earlier, that return skips the postcondition and the write it was meant to guard is committed unchecked. `soma check` warns about an `ensure` placed after a possible `return`; this binary reports the warning as W0014 (habit_warning), not as E0094. Fix it by checking the condition before each early return, or by restructuring so every path falls through to the `ensure`.
