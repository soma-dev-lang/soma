The `memory:` value of a `scale` section must be a size: a number with an optional unit such as 512Mi, 8Gi, 256K, 2G, or plain bytes. A value check cannot read means no memory budget is proven, and the binary says deploy would write the string out as it stands. Replace it with a size such as `"512Mi"`.
