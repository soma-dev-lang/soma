`soma skeleton app.cell --freeze` writes skeleton.lock, and from then on `soma check` refuses with E0121 any program in that directory whose skeletons differ from the frozen ones, printing the changed lines. Here a body wrote `log` outside its frame, and the frame was widened (`writes log` added to `signal pay`) to make that error go away. Restore the frozen skeleton and fix the body instead; when the design itself must change, accept it on purpose with `soma skeleton app.cell --amend`.
