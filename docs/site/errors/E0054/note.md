A test rule calls `transition()`, `get_status()`, `has_state()` or `valid_transitions()` directly while the program has several state machines, so the call cannot tell which machine it means. At run time it would raise an error, which an `assert_fails` would then accept for the wrong reason. Call a handler of the cell that owns the machine instead, for example an `order_status(id)` handler that returns `get_status(id)`.
