When an interior cell handles or awaits a signal that a sibling declares, the parameter types must agree with the sibling's `signal` declaration. Here Checkout sends `total: Int` but Fulfillment's handler takes `total: String`, which `soma check` reports as a signal type mismatch. Make the receiving handler's parameter types match the emitter's signal. (A handler that disagrees with its own cell's face is a different code, E0092.)
