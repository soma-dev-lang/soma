In a skeleton, each signal's frame says what its body may do: `reads`, `writes`, `moves s -> t`, `calls`, `emits`; a signal with no clause is a pure function of its parameters. `soma check` reports E0120 when a flesh body does something its frame does not grant (here `pay` writes `log` while only `ship` may), or when a frame names a slot, an edge or a signal the skeleton does not have. Fix the body when it oversteps the design; change the skeleton only when the design itself is wrong (and run `soma skeleton app.cell --amend` if it is frozen).
