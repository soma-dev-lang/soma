On a Map, `m.size`, `m.len` and `m.length` read the number of entries when the map has no key of that name, so `m.size ?? 1` never falls back to its default. `soma check` warns about `.size` / `.len` / `.length` / `.keys` / `.values` followed by `??`; this binary reports the warning as W0014 (habit_warning), not as E0099. To read a field that is really called `size`, write `m.get("size") ?? 1`.
