An undefined name is normally a check error, but inside `try { }` (or in a handler that a test expects to fail with `assert_fails`) the failure would be caught at run time, so `soma check` reports it as warning W0015 instead; this applies to a plain variable as well as to one inside a `{…}` string interpolation. The danger is that the typo becomes a silently handled error: here `quantiy` makes every call take the error branch, and `unit_price(1000, 4)` returns 0. Fix the name (`quantity`); the message suggests the closest one in scope.
