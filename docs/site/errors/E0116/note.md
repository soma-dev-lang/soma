A face contract (`requires` / `ensures` on a signal) is evaluated on every call and is part of the caller's proof, so it may only compare the signal's parameters (and `result`, in `ensures`) with literals, constants and pure builtins. A clause that reads a memory slot, calls a handler or uses a non-pure builtin, or a contract on a `[native]` handler, is refused with E0116. Keep the part about the parameters in the face (`requires cents > 0`) and move the check against stored data into the handler as a `require ... else Tag`.
