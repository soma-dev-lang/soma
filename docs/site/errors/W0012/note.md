`/` in Soma is exact division, so on two Ints it can give a Float (`7 / 2` is `3.5`), in `[native]` handlers as in the interpreter; `soma check` warns with W0012 when a `[native]` handler divides two Ints, because where the result must be an Int a non-exact quotient fails at run time. Here `unit_price(10, 4)` stops with "the face declares `-> Int` but the handler returned Float 2.5". Write `idiv(a, b)` for the integer quotient (truncated toward zero); `soma fix --native-idiv` makes that rewrite.
