A `let` named like a memory slot hides the slot for the rest of the block: reads, indexes and writes of that name then mean the local, and the slot is never read or written. It used to be a habit warning (W0014), easy to miss among others; it is an error, like a parameter named like a slot. Rename the local (here `counted`). A lambda parameter or a loop variable of the slot's name is still allowed.
