A `let` named like a memory slot hides the slot for the rest of the block: reads, indexes and writes of that name then mean the local, and the slot is not read or written. In edition 2026 `soma check` warns about this under the code W0014 (habit_warning); in edition 2027 it is the error E0080, as a parameter named like a slot already is. Rename the local (for example `stock_count`). A lambda parameter or a loop variable of the slot's name is still allowed.
