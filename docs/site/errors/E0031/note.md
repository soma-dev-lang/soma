A `promise` in a face must name one of the structural promises that `soma check` can test (all_persistent, all_encrypted, all_consistent, has_memory, has_face, has_signals, has_auth), combined with `&&`, `||` and `!`. Anything else, such as a comparison on stored values, is refused because a promise that no check backs would prove nothing. Move a bound on stored values into the cell's `memory` as an `invariant`, which is checked before every write; to keep a sentence as documentation only, quote it: `promise "balances never go negative"`.
