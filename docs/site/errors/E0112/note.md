The `edition` key under `[package]` in soma.toml must name an edition this toolchain knows; this binary knows "2026" (the default when the key is absent) and "2027", and refuses any other value with E0112 on every program checked beside that manifest. The error lies in soma.toml, not in the program, so the cell does not change: correct the value, here from "2025" to "2027", or delete the key to get edition 2026. `soma fix --edition 2027 app.cell` moves a program to edition 2027 and writes soma.toml for you.
