When two cells define a handler with the same name, a bare call to that name inside one of them runs that cell's own handler, and `soma check` warns with W0011 because the other one might have been meant. From a third cell the same bare call is an error, since neither is preferred. Qualify the call with the cell name (`Orders.pack(order_id)` or `Warehouse.pack(order_id)`) to say which handler runs.
