A `[native]` handler is compiled to Rust and may only use the native vocabulary: Int, Float, Bool and String values, arithmetic, `if`, `while`, `for i in range(a, b)`, and the buffer, hashmap and strbuf primitives. Lists, maps, method calls, slots, `try`, `match` and interpolation are refused at check time, and the message names the first construct found. Rewrite the loop with scalar locals (an accumulator instead of a list), or drop `[native]` and let the interpreter run the handler.
