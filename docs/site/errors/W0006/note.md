A face `await name(...)` says the cell expects to receive the signal `name`, so `soma check` warns with W0006 when the cell has no `on name(...)` handler for it. It is a warning rather than an error because the signal might be delivered over the bus from another process, but within one program an awaited signal with no handler does nothing in that cell. Add the handler with the same parameters (`on withdraw(account: String, amount: Int) { … }`), or remove the `await` from the face.
