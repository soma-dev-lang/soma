W0018 is a type finding of the inference pass that `soma check` reports as a warning and leaves to the run-time check; the message says it becomes an error in edition 2027. Here the handler returns a Map through a local while the face declares `-> String`, and `soma run` stops with "the face declares `-> String` but the handler returned Map". Make the value and the face agree, here by declaring `-> Map` (returning the Map literal directly, without the local, is already error E0040). The same code W0018 is also used for an untrusted value, a model's or an HTTP reply, that decides a `transition()` target or a URL without a check.
