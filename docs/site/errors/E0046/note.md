A parameter, return or slot type uses a name that is not declared but is close to a built-in type or is a common alias from another language, such as `Integer`, `Text`, `Boolean` or `Dict`. Soma refuses it because an undeclared type name would accept any value at run time. Use the Soma type the message suggests (`Int`, `String`, `Bool`, `Map`, …). In 3.1.0 an undeclared name that is not close to a built-in type, such as a misspelt `cell type` name, is not reported.
