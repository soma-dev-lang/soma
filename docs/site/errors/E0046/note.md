A parameter, return or slot type uses a name that is not declared but is close to a built-in type or is a common alias from another language, such as `Integer`, `Text`, `Boolean` or `Dict`. Soma refuses it because an undeclared type name would accept any value at run time. Use the Soma type the message suggests (`Int`, `String`, `Bool`, `Map`, …). Any other undeclared name (`q: Lots` with no `cell type Lots`), and a parameterised scalar such as `Int<lots>`, which checks nothing, are warning W0018 in edition 2026 and this error in edition 2027.
