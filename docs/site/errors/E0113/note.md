A model's answer (`think()`) or an HTTP reply is untrusted: it may be stored, shown and computed with, but it may not decide the target of a `transition()`, a URL, a file path or `set_budget` until the handler tests it. In edition 2027 `soma check` refuses such a use with E0113; in edition 2026 the same program gets a warning under W0018 that says it becomes an error in 2027. Test the value first, with `require contains([...], verdict) else BadVerdict` or a `match` on the values you allow, so a prompt-injected answer cannot pick the state.
