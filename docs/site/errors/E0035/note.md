`.set()` and `.delete()` used as a value on a local map are refused: they are slot methods and, on a local, they do not return the updated map. Written as a statement (`line.set(k, v)`), the call does change the local and passes check; it is the expression form (`let priced = line.set(…)`) that is the error. Write the local with brackets (`line["total"] = v`) and use the variable itself, or rebuild it (`line = without(line, k)` to remove a key).
