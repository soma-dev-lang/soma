The condition of a rule's `requires` is outside the closed language of the law. A condition is made of `not`, `and`, `or`, parentheses, a state of a parameter (`frozen(h)`) and a comparison between an Int state or an Int parameter and a number or a parameter. There is no arithmetic, no call and no quantifier: the owner of the law must be able to read it. A rule that does not fit stays a sentence, served by a refusal `under` its identifier.
