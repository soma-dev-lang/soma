A rule in a `cell test` calls a function that no cell of the program defines as a handler and that is not a builtin. Soma reports it at check time because the call would otherwise only fail when `soma test` runs the rule. Call the handler by the name the program gives it, or define the missing handler. In 3.1.0 this code is used for calls inside test rules; the same mistake inside a handler body is reported as E0012.
