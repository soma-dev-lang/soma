`transition()` takes 2 arguments (the instance id and the target state) or 3 (the id, the source state and the target state); with any other count `soma check` reports E0106, and this binary reports the same call a second time as E0101 (builtin arity). The first argument is the id of one instance, such as an order, not the machine's name, so `transition("shipped")` has lost it. Pass the id: `transition(order_id, "shipped")`. A call to your own handler with the wrong number of arguments is reported as E0012 (dispatch), not as E0106.
