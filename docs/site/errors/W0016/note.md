When a cell declares a memory budget (`scale { memory: "128Mi" }`), `soma check` tries to prove the cell's peak memory stays under it; W0016 is the advisory it prints when a handler allocates something with no static bound, so the proof is incomplete. It names each such call site, here `http_get`, whose response size is not bounded. Bound the allocation, here with the `max_bytes` option (`http_get(url, map("max_bytes", 65536))`), and check then reports that the budget holds.
