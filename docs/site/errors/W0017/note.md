When a cell declares a memory budget in its `scale` section (`memory: "256Mi"`) and the static analysis can bound the cell's peak memory, `soma check` prints a note such as "✓ budget holds for cell 'Summarizer' while its slots stay within their assumed sizes: peak ≤ 26.48 MiB ≤ declared 256.00 MiB", with a breakdown. The bound assumes each slot stays within its `[capacity(N)]`, `[max_key_bytes(N)]` and `[max_value_bytes(N)]` annotations (or default sizes), and the note says these are not enforced at run time. It is informational: nothing needs fixing.
