E1002 is meant for a file that ends inside a construct, but this compiler reports that case under E1001 instead: a missing closing brace at the end of the file gives `expected '}', found end of file`. An unterminated string or block comment is a lexer error, E1010. The fix in every case is to close the construct that is still open: count the `{` and `}` of the last cell and handler.
