`soma check` knows how many arguments each builtin takes and reports E0101 when a call passes too many or too few, also in method form, where the value before the dot counts as the first argument. Soma's `split(text, sep)` has no limit argument like Python's `maxsplit`, and the message says the extra argument would have been silently ignored. Pass only the arguments the builtin declares; `soma describe --builtins --json` lists every signature.
