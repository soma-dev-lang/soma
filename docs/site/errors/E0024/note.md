A transition guard (`a -> b { guard { amount <= 1000 } }`) reads the locals of the handler that calls `transition()`, plus the cell's slots and `_id` / `_from` / `_to`. If a handler that transitions toward the guarded state does not bind every name the guard reads, the guard could not be evaluated, so `soma check` refuses it. Bind the name in that handler — here by taking `amount` as a parameter — or have the guard read a slot keyed by `_id`.
