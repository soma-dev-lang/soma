In Soma a new variable is introduced with `let`; a plain `totl = total + p` to a name that has no `let` creates a new variable, so a typo silently leaves the real variable unchanged. `soma check` warns about it, and this binary reports the warning as W0014 (habit_warning), not as E0104; nothing is reported when the name is also a builtin, such as `sum`. Declare the variable with `let` before assigning it, or correct the name if you meant an existing one.
