`soma check` infers the types of expressions and reports E0109 when one cannot be used where it stands, such as `+` between a String and an Int, a comparison of a String with an Int, or an ordering against `()`. Soma does not convert silently: adding a String and an Int fails at run time with "cannot add String and Int", so check refuses it when it can see both types. Build text with interpolation (`"{customer}: {total_cents} cents"`) or `to_string(n)`, and parse text with `to_int` / `to_float` when you mean a sum.
