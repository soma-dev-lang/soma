A `promise` in a face written as free text (`promise "answers in under two seconds"`) is something the compiler cannot check, so `soma check` treats it as documentation and prints a note saying so. It does not fail the check. If the promise matters, express it as something the compiler does check, such as a memory invariant, a face `requires` / `ensures` clause, a `cost` bound or a `soma.toml` verify property.
