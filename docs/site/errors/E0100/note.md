A `cost { tokens: N }` declaration is a promise that `soma check` must prove: every `think()` needs a literal `max_tokens`, and every loop around a `think()` needs a known number of iterations. A loop over a list of unknown length makes the bound unprovable, and a declared bound that cannot be proven is an error (E0100), not a note. Annotate the loop with `for [loop_bound(50)] t in tickets` (more iterations raise kind `loop_bound` at run time), or remove the cost declaration; here 50 × 100 reply tokens fits the declared 5000.
