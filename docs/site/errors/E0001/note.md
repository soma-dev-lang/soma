Some memory slot properties exclude each other: `[persistent]` and `[ephemeral]`, `[consistent]` and `[eventual]`, `[immutable]` and `[evict]`, `[ephemeral]` and `[retain]`. `soma check` refuses a slot that carries both sides of such a pair, because the storage could not honour both promises. Keep the one property that says what you mean — here, session tokens that need not survive a restart are `[ephemeral]` only.
