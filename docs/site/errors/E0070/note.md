When `on request` declares a fourth or fifth parameter, they receive the URL query and the request headers as a Map of String to String, so they must be declared `Map`, `Map<String, String>` or `Any`. `soma serve` refuses the same signature at start-up, so check reports it first. Declare the parameter `headers: Map` and read a header by its lower-case name, such as `headers["user-agent"]`.
