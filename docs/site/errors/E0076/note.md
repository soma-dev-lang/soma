An unescaped `"` inside `{...}` ends the string literal, so `"Invoice {id}: {if paid { "paid" } else { "due" }}"` is split into several pieces. `soma check` warns that a string literal ends inside `{...}` under the code W0014 (habit_warning), and the leftover pieces are reported as errors. Bind the inner value first (`let state = if paid { "paid" } else { "due" }`, then `"{state}"`), or escape the quote.
