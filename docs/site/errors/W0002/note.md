Some slot properties imply others: `[immutable]` implies `consistent`, and a `cell property` can declare `implies [...]`. When a slot has a property whose implied property is not written, `soma check` adds it automatically and prints a note such as "'immutable' on 'entries' implies 'consistent' (added automatically)". It is informational: the program passes, and writing the implied property on the slot makes the note go away.
