Inside an `interior` block, `soma check` warns with W0001 when a cell's face declares a signal that no sibling cell handles and no cell awaits; the message says the signal "will be lost". In this compiler the warning comes together with error E0003, because a face signal must also have an `on` handler in its own cell. Add the missing handler (`on cancel(id: String) { … }`) or remove the signal from the face. An `emit` of an event nobody handles is a different diagnostic: it is reported as W0011.
