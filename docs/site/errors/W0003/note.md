A memory slot's properties in `[...]` must be ones Soma or a loaded `cell property` defines; an unknown name is not an error, but it does nothing, and `soma check` warns with W0003 and suggests the closest known property. A misspelled `[persistant]` therefore leaves the slot without the persistence the programmer meant. Correct the spelling (`[persistent]`), or define the property with `cell property persistant { }` if it really is your own.
