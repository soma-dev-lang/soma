In `for line in lines { … }` the loop variable is a copy of the element, so a write such as `line.price = …` is lost when the iteration ends unless the copy is used afterwards. `soma check` 3.1.0 reports this as the warning W0014 rather than under E0043. To keep the change, loop over indices and write the element back: `for i in range(0, len(lines)) { let line = lines[i]  line.price = …  lines[i] = line }`.
