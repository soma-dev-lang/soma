A structural `promise` in a cell's face (`all_persistent`, `all_consistent`, `all_encrypted`, `has_memory`, `has_face`, `has_signals`, `has_auth`) is checked against the cell's structure. `promise all_persistent` requires every memory slot to be marked `[persistent]`; one `[ephemeral]` slot breaks it. The message does not name the offending slot, so look at each slot's properties, then mark it `[persistent]` or remove the promise.
