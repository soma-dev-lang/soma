When a call passes a value whose type `soma check` can tell (a literal, or a local whose type it inferred) to a handler parameter declared with a different type, it reports E0105 at that argument, before the program runs. The fix is to pass a value of the declared type or to change the parameter's type. Here money is kept in Int cents, so the shipping fee is `499`, not `4.99`; an Int is accepted where a Float is declared, but not the reverse.
