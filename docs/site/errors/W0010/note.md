When a cell declares `cost { tokens: N }` and every `think()` call it can make has a literal `max_tokens` cap and runs a known number of times, `soma check` proves the bound and prints a note such as "✓ cost: 'tokens' bound proven — peak 500 reply tokens (the max_tokens caps) ≤ declared 500". The bound covers reply tokens only; prompt tokens are capped separately with `set_budget`. This is good news, not a fault: nothing needs fixing.
