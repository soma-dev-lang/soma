A `maps` reads a state of the law through a signal that has no body yet. Until that signal is filled the state cannot be read, and a guard derived from it judges nothing: the call fails with kind `not_implemented`, naming the state and the hole — not with the rule. `soma check` reports this as the warning W0020 law_warning, never as E0141, and `soma law` shows the rule as `checked (derived, awaiting Cell.signal)`. Read the memory directly in the `maps` when the fact is a slot of the cell, or fill that signal first.
