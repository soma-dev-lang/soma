When `soma check` knows a value's record type (a `cell type` with one variant with named fields, here `Line`), reading a field the type does not declare is reported as E0110, with the list of the fields it does have. At run time an undeclared field reads as `()`, so `l.quantity * l.unit_cents` would fail at run time instead of naming the typo. Use the declared name (`l.qty`), or add the field to the type. The same code covers a field no variant of a sum type declares, and a field other than `value`, `error`, `kind`, `detail` read on a `try` result.
