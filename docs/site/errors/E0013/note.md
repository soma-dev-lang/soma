Inside an `interior` block, sibling cells are wired by name: an `await x(…)` in one cell's face must match a `signal x(…)` that a sibling declares. `soma check` reports an await that no sibling emits (here `order_paid`, while Checkout only emits `order_placed`), since it would never be delivered. Await the signal a sibling actually declares, or add that signal to the sibling that should send it.
