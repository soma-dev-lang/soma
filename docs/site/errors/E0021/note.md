A `memory: "64Mi"` line in a cell's `scale` section is a budget that `soma check` compares with the peak memory it computes for the cell (slots, the largest handler, state machines, runtime). Building a list of nine million Ints in one handler gives a peak of about 161 MiB, so the 64 MiB budget is refused. Raise the budget above the reported peak, or change the handler so it does not build the large value (here `len(range(0, n))` is just `n`).
