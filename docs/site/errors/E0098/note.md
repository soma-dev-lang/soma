`soma check` reports E0098 when two edges of a state machine cover the same move from the same state with different guards, here the wildcard `* -> cancelled` and `paid -> cancelled { guard { refunded } }`. A `transition()` takes the first edge that matches, so the later edge's guard is never evaluated (or, in the other order, the first edge's guard refuses a move the second allows). Declare each move once: keep the guarded state out of the wildcard with `except [...]`, adding it to the states already listed there.
