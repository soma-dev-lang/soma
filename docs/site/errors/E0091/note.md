Names that other languages use for null, booleans, bindings or functions (`null`, `None`, `nil`, `True`, `var`, `def`, `this`, `and`, `or`, `not`, …) do not exist in Soma, and `soma check` reports them as E0091 instead of a plain undefined name. The message names the Soma form: null is `()`, booleans are `true` / `false`, bindings are `let`, and the boolean operators are `&&`, `||`, `!`. Here `n == null` becomes `n == ()`; `stock.get(sku) ?? 0` would also do.
