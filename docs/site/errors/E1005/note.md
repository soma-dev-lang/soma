Some keywords (`agent`, `tool`, `cell`, `on`, `given`, `promise`, `use`, `in` and others) can never be used as a variable, parameter or field name, because the parser reads them as the start of a construct. `soma check` names the word and suggests a rename such as `agent_id`. Rename the parameter (here `agent` becomes `assignee`); to read a JSON field with that name, index it with a string: `d["agent"]`.
