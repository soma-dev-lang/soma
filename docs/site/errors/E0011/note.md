Every `{name}` inside a string literal is interpolated, and `soma check` refuses one whose name is not a let, parameter, loop variable, match binding or memory slot in scope — here the typo `custmer`, for which it suggests `customer`. Without this check the misspelling would only fail when the handler runs. Fix the spelling or bind the name first; for literal braces write `{{` and `}}`. With this binary the same code E0011 is also given to an undefined name outside any string.
