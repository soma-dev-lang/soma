`think(prompt, map("requires", ["vision"], …))` declares capabilities the model must have, and `soma check` compares them with the model the agent resolves to: from soma.toml's `[agent]` section, or a `[models.<name>]` section the cell selects with `cell agent Name [model: name]`. Here the default model `gemma3:12b` does not advertise `vision`, so check fails instead of the call failing at run time. Point the agent at a model that has the capability (as here), or list the capability under that model's `capabilities = [...]` in soma.toml if you know it has it.
