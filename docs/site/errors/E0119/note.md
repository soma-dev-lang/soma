A `flesh` block holds the bodies of a `skeleton` of the same name, and each body must fit its signal: same parameter names in the same order, with the types taken from the signal. `soma check` reports E0119 for a flesh whose parameters differ from the signal's (here `amount` instead of `cents`), a flesh with no skeleton of that name, a second body for one signal, or a private helper with an untyped parameter. Write the parameters exactly as the signal names them, `on deposit(owner, cents)`; `soma skeleton app.cell Wallet.deposit` prints the brief with the signature to copy.
