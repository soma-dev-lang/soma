A syntax error means the parser could not read part of the program as Soma. This binary reports each syntax error under a more precise code from E1001 to E1010 (for example E1001 when one token was expected and another found, E1003 for a return type written on a handler instead of on its face signal), never as E0108. Run `soma explain` with the code the diagnostic prints to see what that class means; the message itself names the token expected or the correction.
