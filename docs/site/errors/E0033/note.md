The options map passed to `think()` accepts only max_tokens, max_rounds, timeout (in milliseconds), tools_allowed and requires; any other key, such as "temperature", is a check error. Soma refuses unknown options at check time because they would otherwise be rejected when the model is called. Remove the option, or for a typed answer use `think_json(prompt, map("as", "TypeName"))`, whose `as` must name a declared `cell type`.
