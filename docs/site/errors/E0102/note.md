The budget annotations `capacity(N)`, `max_key_bytes(N)`, `max_value_bytes(N)` and `max_element_bytes(N)` on a memory slot, and `max_instances(N)` on a state machine, feed the memory proof, so each must carry exactly one non-negative whole number. Anything else (a string such as `"50k"`, a Float, no argument, several arguments) is refused with E0102, because the proof would otherwise silently fall back to the default. Write the number itself, `capacity(50000)`; underscores such as `50_000` are allowed in Int literals.
