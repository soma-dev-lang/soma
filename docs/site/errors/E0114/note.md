`use name` loads name.cell beside the program, `use lib::name` loads lib/name.cell, and otherwise an installed package; when none of these exists the program does not load, and `soma check` stops with E0114. The plain output prints which files it looked for, without the code; `soma check --json` gives the code E0114 but only the message "the program does not load (details on stderr)". Name the module after its file: here the file is pricing.cell, so the line is `use pricing`.
