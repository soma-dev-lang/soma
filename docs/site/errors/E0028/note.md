E0028 (`undefined_variable`) names the rule that every name must be a let, parameter, loop variable, match binding or memory slot in scope. With soma 3.1.0, `soma check` reports an undefined name under E0011 (`interpolation_undefined`) instead, both inside and outside strings, with the message "undefined variable '…' — no let, parameter, loop variable, match binding or memory slot with that name is in scope" and a "did you mean" suggestion when a close name exists. Fix it by binding the name before its use or correcting its spelling; see E0011 for a checked example.
