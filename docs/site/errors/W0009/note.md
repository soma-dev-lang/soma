W0009 was the warning for a `cost` bound that is only an estimate. In this compiler a declared `cost { tokens: N }` is either proven (a note) or refused: a bound that cannot be proven, such as a `think()` without a literal `max_tokens` or in a loop of unknown length, is error E0100 cost_unprovable. Give every `think()` a literal `max_tokens` and bound its loops (`for [loop_bound(50)] x in xs { … }`) so the bound can be proven.
