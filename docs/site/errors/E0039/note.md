Some builtins, such as `regex_match`, answer an Int (1 or 0), not a Bool, and a condition in Soma must be a Bool. `soma check` refuses such a call used directly as a `require` or `if` condition. Compare the result explicitly: `require regex_match(email, pattern) == 1 else InvalidEmail`. In 3.1.0 a plain Int variable used as a condition (`if on_hand { … }`) is reported as E0109 instead.
