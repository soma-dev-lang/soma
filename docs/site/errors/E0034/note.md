Every memory slot is stored in a table named `<Cell>_<slot>`, and each slot also uses a second table with `_log` appended; table names ignore case. A slot `stock` therefore already owns `Inventory_stock_log`, so a second slot named `stock_log` would share it and the two slots would overwrite each other's data. Rename one of the slots; slot names starting with `__` are refused for the same reason, since the runtime keeps state machine instances under `__sm_…`.
